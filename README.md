# Heart Disease Prediction System

A simple machine learning web application that predicts heart disease using patient health data.

## Project Overview
This project uses a Decision Tree machine learning model to predict heart disease based on health-related input features. The application provides a simple interface built with Streamlit.

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## Project Files
- `project.py` — Streamlit application.
- `train_model.py` — Script for training and saving the machine learning model.
- `heart.csv` — Dataset used to train the model.

## How to Run
1. Install the required libraries.
2. Run `train_model.py` to train and save the model.
3. Run the application using Streamlit:
   `streamlit run project.py`
